Forecasts each GTA VI trophy's Exophase earn rate at 2026-11-26T00:00:00Z. It fits earners and players-tracked separately as power laws in log time, so a refresh that jumps the tracked count cannot drag the forecast down, then divides the two for the rate, with chapter order and platinum caps.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
